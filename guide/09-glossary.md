# Glossary

| Term | Plain meaning |
|---|---|
| **Knowledge base (KB)** | One folder holding all data of one project: a database plus stored files |
| **`rkb`** | SciVetra's command, typed in the work window |
| **Virtual environment (`env`)** | A private copy of Python packages for SciVetra, so nothing else on your computer is affected |
| **Terminal / PowerShell** | The window where you type commands |
| **JSON** | The `"name":value` text format that `rkb` prints |
| **DOI** | A paper's permanent identifier, e.g. `10.1234/abcd` |
| **Reprovane** | The screening tool where official review decisions live |
| **PBD** (PaperBatchDownloader) | The tool that downloads PDFs from a list |
| **Usage rights** (gates A1–A10) | Questions such as "may we store, process, show, quote, share or send this to an AI?". The answer is **no** until assessed. |
| **OAG** (Owner Approval Gate) | A decision only the **project owner** may take: using real data, enabling online AI, sharing outside |
| **Evidence** | A value, result or limitation from a paper, with page and character positions |
| **Claim** | A statement in a draft that must be supported by evidence |
| **SUPPORTED** | Fully supported by current, accepted evidence; cited `[1]` |
| **PARTIAL** | Partly supported, missing context, or waiting for a human to confirm |
| **UNSUPPORTED** | The evidence says something else, or the wording contradicts the numbers |
| **MISSING_EVIDENCE** | No accepted evidence |
| **STALE_SOURCE** | The source file changed or was damaged |
| **BLOCKED_RIGHTS** | The usage rights no longer allow it |
| **CONFLICTING** | The same paper reports two different values for one measurement |
| **NON_AUTHORITATIVE** | A proposal or draft, not an official decision |
| **Reviewer** | A registered person who checks work; nobody may review their own work |
| **Backup / restore** | A safe copy of a KB, and turning that copy back into a (new) KB |
| **Upgrade** | Moving a KB to the structure of a newer SciVetra version (backed up first) |
| **SHA-256** | A file's fingerprint; changing a single byte changes it |
| **Sandbox** | An isolated process with strict limits, used to read untrusted PDFs |
