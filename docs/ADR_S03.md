# S03 architecture decisions and deviations from S01 v03 (PROPOSED shapes)

Status: implementation decisions of the S03 v01 candidate. Each row says what the code does, why, and whether the architect must decide. No S01 identifier, enum value or scientific policy was silently revised; where a shape had to differ, it is listed here.

## 1. Decisions (ADR-S03-xx)

| ADR | Decision | Reason | Architect action |
|---|---|---|---|
| ADR-S03-01 | Migration `0002_global_research_library.sql` is purely additive (22 new tables, 2 views, triggers). Nothing in 0001 is altered; 0001 keeps SHA-256 `2c07dd34…71f38b` | S03 prompt S03-A items 1-2 | none |
| ADR-S03-02 | S01 "S" (state) columns are **projections over append-only event tables**, never updated columns: paper kind (`paper_kind_event`), assertion status (`assertion_status_event` + view `identity_assertion_effective`), paper identity state (`DISPUTED` while an IdentityConflict is open), link state (`paper_asset_link_event` + view `paper_asset_link_effective`), member confirmation (`work_family_member_event`), workspace availability (`workspace_availability_event`), link-candidate state (`link_decision`) | 0001 makes `global_paper` and `identity_assertion` immutable (every table append-only). Editing them would rewrite S02 history | confirm |
| ADR-S03-03 | `rkb upgrade` = verify ledger → writer lock → verified backup to the operator target → backup-API copy → migrate the copy → integrity/FK/ledger/domain verification (all 21 0001 tables byte-identical, S02 semantic manifest identical) → keep `kb.sqlite.pre-<v>-<UTC>` → atomic replace. No other command migrates | S01 10 §3 | none |
| ADR-S03-04 | **Reversible merge/split is NOT implemented.** `LinkDecision SAME_MANIFESTATION` is recorded and shown, but papers are not merged; `merged_into_paper_id` stays unused | The prompt allows merge/split only if completely specified and tested; GP-1's "split re-points assertions" needs a specification of re-pointing for PPRs, DocumentVersions and links that S01 does not give | specify merge/split semantics for a later stage |
| ADR-S03-05 | IdentityConflict resolution actions (new, S01 lists only "merge, split, or mark RETRACTED_ASSERTION"): `ASSERTIONS_WITHDRAWN`, `DOI_SELECTED_FOR_ITEM` (activate one DOI, withdraw others), `CONFIRMED_DISTINCT_MANIFESTATIONS` (papers stay separate, conflict closed), `DEFER`. Each needs an operator label, a reason and ≥ 1 resolvable evidence ref (assertion id, snapshot id or `sha256:` of a registered operator document). Activation that would map one identifier to two papers is refused (`IA1_WOULD_BE_VIOLATED`). DB triggers refuse an assertion status change without a raised conflict (→ CONFLICTING only) or a matching human resolution | Human-anchored resolution without merges | confirm the action vocabulary |
| ADR-S03-06 | The library import (`rkb library import-reprovane`) is the S03 path. The S02 command `rkb metadata import-reprovane` is kept unchanged for compatibility (it still mints one paper per release item and registers no workspace/PPR) | Preserves the 163 accepted S02 behaviours. Running both on the same workspace would create duplicate papers; the S03 linker then sees several MLI candidates and raises `DOI_COLLISION` instead of auto-linking, and `doctor --full` reports the S02-layer IA-1 violation | decide whether to retire the S02 command in S04 |
| ADR-S03-07 | G1 validator `rkb-pdf-structure/1` is a stdlib, conservative parser running in an isolated child (`-I -S -B`, empty environment, wall-clock timeout, self-applied memory cap: Windows job object / POSIX `RLIMIT_AS`, no child processes, audit hook refusing open/socket/process events after the input is read). It accepts only classic xref tables and unfiltered/FlateDecode streams; anything else is `PARSER_REJECTED`. pypdf strict open is an optional second stage (`--pypdf-site`, isolated copy) | No dependency may be downloaded; synthetic fixtures are classic PDFs | Most real-world PDFs use xref/object streams and would be refused by the stdlib stage: S04/S06 must adopt the pypdf (or equivalent) sandbox as the primary G1 path. Decide before real-PDF intake |
| ADR-S03-08 | Journal mode stays `DELETE` (accepted S02 trade-off) | prompt §2 | none |
| ADR-S03-10 | **(v02, S03-F01)** Open-licence recognition is a complete-URI allowlist (`cc-uri-allowlist/2`): `http(s)://[www.]creativecommons.org/licenses/<family>/<version>[/[deed[.<lang>]\|legalcode[.<lang>]]]` for BY, BY-SA, BY-ND, BY-NC, BY-NC-SA (1.0, 2.0, 2.5, 3.0, 4.0), BY-NC-ND (2.0-4.0), BY-ND-NC (1.0 spelling), and `/publicdomain/zero/1.0`, `/publicdomain/mark/1.0`. Host case-insensitive, path case-sensitive. Refused: userinfo, any port, query, fragment, `%`-encoding, whitespace, backslash, non-ASCII, empty segments, extra segments, unsupported versions and **jurisdiction ports** (`/by/3.0/us/`). A refused URI is L3 (unrecognized licence), so with OA availability the class is at most PUBLIC_OA_UNVERIFIED. The stored policy id stays `rights-policy/1` because migration 0002 pins it with a CHECK (no migration change allowed); the rule revision is reported as `evaluation.licence_uri_rules`. History is never rewritten: v01 assessments stay; `doctor --full` lists current LICENSED rows the new rules no longer support (`RIGHTS_REASSESSMENT_DUE`), and re-running `rights assess` appends a superseding row | Architect review S03-F01; CC URI structure (CC wiki "License Versions") | confirm the allowlist; decide whether jurisdiction ports should be recognized (needs a reviewed port list) and whether a later migration should allow a new policy id |
| ADR-S03-11 | **(v02, S03-F02)** Backup completeness is referential: the DB snapshot is the authority for which CAS objects must exist (`cas.CAS_REFERENCE_COLUMNS`: provider_snapshot.response_bytes_sha256, operator_document.document_sha256 for schema ≥ 1; pdf_asset.asset_sha256 and the four reprovane_release_import component hashes for schema ≥ 2). doctor, create_backup, verify_backup and restore_backup share it. Unreferenced hash-valid objects are still copied (doctor warns); temp/invalid/link entries in the source are skipped and counted; any non-object entry or link inside a backup is refused. Manifest and SHA256SUMS are integrity records, never proof of completeness or authenticity | Architect review S03-F02 | none |
| ADR-S03-09 | `rights-policy/1` never yields ALLOW for `redistribute` or `external_ai_process`; DB CHECKs additionally require an `owner_approval_ref` for either ALLOW and forbid ALLOW for UNKNOWN / UNVERIFIED / RESTRICTED | 05 §4.2-4.3, OAG-6 closed | none |

## 2. Deviations from S01 v03 field specifications

| # | S01 element | S03 implementation | Why |
|---|---|---|---|
| D1 | RightsAssessment prefix `ra_` | `rga_` | `ra_` is already used by S02 `ra_claim` |
| D2 | `global_paper.identity_state`, `manifestation_kind` as S columns | columns keep their insert values; effective values are projections (ADR-S03-02) | immutable 0001 table |
| D3 | `IdentityAssertion.status` S column | effective status = latest `assertion_status_event`, else the stored value | immutable 0001 table |
| D4 | PaperAssetLink "PENDING_REVIEW" (S03 prompt) | `UNVERIFIED` (the S01 enum) + operator review queue; quarantine = `AMBIGUOUS` | S01 enum has no PENDING_REVIEW |
| D5 | G3 negative items → "QUARANTINED" | link `identity_state = AMBIGUOUS` with reason codes (`DOI_MISMATCH`, `SUPPLEMENT_SUSPECTED`, `MULTI_ARTICLE_PDF`, `OTHER_VERSION`, `SCANNED_NO_TEXT`); `MISMATCH` is set only by a human REJECT | `MISMATCH` is a verdict, quarantine is a review state |
| D6 | PdfAsset `structural_validation`, `quarantine_state`, `current_rights_assessment_id` columns | validation results in `asset_validation_event`; quarantine per import (`import_event.outcome = QUARANTINED`, e.g. `CAS_MISMATCH`) and per link (`AMBIGUOUS`); current rights = latest `rights_assessment` row | append-only design; no S column on assets |
| D7 | `ImportEvent.idempotency_key` UNIQUE | unique only for `REGISTERED` rows (partial index); REJECTED/DUPLICATE attempts are journaled repeatedly | retries must be auditable |
| D8 | C1 compares the KB paper's `manifestation_kind` | effective kind = operator `paper_kind_event`, else the single kind mapped from the work_type claims of the paper's own RV references (versioned table `WORK_TYPE_KIND`, link-policy/1) | papers minted from RV items have no other kind evidence; conservative (more conflicts, never fewer) |
| D9 | L5 WorkFamily proposal when an OpenAlex-only signal pairs different DOIs or kinds | also on `VERSION_CONFLICT`; roles from kind (`PREPRINT`, `VERSION_OF_RECORD`, `CONFERENCE_VERSION`, `RELATED_DATASET`, `RELATED_SOFTWARE`, else `OTHER`) | S01 example roles only |
| D10 | L2 title similarity ≥ 0.9 | token-set Jaccard after NFKC/casefold/punctuation stripping (05 §3 E2 method), against titles carried by other papers' RV references; signal only | no other title source in S03 |
| D11 | `scope_ref` for RV context identifiers | `wsr_…` workspace ref (S01). Semantic hashes use the workspace's semantic hash, not the ID (`scope_semantic`) | S02 used text `rv:<label>:<release>`; IDs must not enter semantic hashes |
| D12 | Repeated `publication_entity_id` in one export | refused by the library import (`EXPORT_DUPLICATE_IDENTIFIER`); the S02 import keeps accepting it | the S02 synthetic fixtures reuse one entity id; native exports never do |
| D13 | identity-policy/1 E5 (page count vs `pages` claim) | not evaluated | no `pages` claim source for RV-minted papers |
| D14 | `rkb reconcile --workspace-ref` | `--workspace-label` + `--export-dir`; read-only; `SOURCE_UNAVAILABLE` is the separate operator command `library workspace-status` | labels are the operator-facing key |
| D15 | Backup manifest "rights class counts" | counts of the latest assessment per (asset, document version) | rights attach to bytes + version |
| D16 | Writer commands | take the OS writer lock (creating `.rkb-writer.lock`) before the schema check refuses an old/new schema; DB, CAS and ledger are untouched | unchanged S02 behaviour |
